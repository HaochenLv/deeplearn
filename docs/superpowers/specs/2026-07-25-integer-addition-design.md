# 整数加法课程学习 + 长度外推实验 — 设计文档

- **日期**: 2026-07-25
- **状态**: 已确认，待实现
- **工作目录**: `/home/eric/deeplearn`

## 1. 目标

研究微型 Transformer 能否通过**纯课程学习（1→2→3→4 位逐级）+ Scratchpad/CoT**学会整数加法，并对**训练中从未见过的更长位数（5–8 位）保持准确率**（长度外推）。

次要观察：

- **Grokking**：loss 早已平、准确率在某刻突然跃升的相变现象。
- **灾难性遗忘**：升级到更长位数后，短位数准确率是否回落。

## 2. 范围与算力

- 训练长度：`d = 1, 2, 3, 4`
- 外推测试长度：`5, 6, 7, 8`
- 算力：单机 CPU（与 MNIST 实验同机），微型模型，每阶段预计分钟到几十分钟。

## 3. 设计决策（已锁定）

| 决策点 | 选择 | 理由 |
|---|---|---|
| 数字表示 | 字符级字符串 | 人类看到的就是符号；迫使模型学算法而非拟合加法函数 |
| 产出方式 | Scratchpad/CoT | 显式写出进位中间步骤，最像儿童打草稿，且对长度外推帮助最大 |
| 课程策略 | 纯课程，保留旧长度数据 | 逐级练到收敛再升级；保留旧数据防遗忘 |
| 模型 | 微型 decoder-only Transformer | 算法学习/长度外推研究的标准配置，CPU 友好 |
| 核心现象 | 长度外推/泛化 | 头条评估指标 |

## 4. 表示与 Scratchpad 格式（竖式）

字符级分词。词表（≈16 token）：`0-9`、`+`、`=`、`d`（写本位数字）、`c`（进位）、换行 `\n`、`<eos>`、`<bos>`。

**Scratchpad 规则（逐列竖式，从个位到高位）**：每列占一行，统一模板

```
<本位a> + <本位b> + <进位入> = <和> d<写本位> c<进位出>
```

最后单独一行给出正常读序的答案。每列结构完全一致——这是外推的根基（任意位数都是同一过程的重复）。

示例：

```
输入: 37+48=
目标:
7+8+0=15  d5 c1
3+4+1=8   d8 c0
=85
```

进位传播（结果比操作数更长）：

```
输入: 85+16=
目标:
5+6+0=11   d1 c1
8+1+1=10   d0 c1
0+0+1=1    d1 c0
=101
```

- 操作数前导零对齐（简化列对齐问题）。
- 余进位规则：操作数耗尽后若仍有进位，继续发 `0+0+<进位入>` 列，直到进位为 0（如上例第 3 行），自然处理任意长度的进位传播。
- 末行 `=<答案>`：把各列写下的数字按「个位→高位」倒序抄成正常读序。
- 相比内联写法，竖式每列一行、可读性更强、更像儿童打草稿；代价是目标序列略长（token 稍多，对本微型模型影响可忽略）。

## 5. 数据生成（`data.py`）

- 给定位数 `d`，均匀随机生成两个 `d` 位数（允许前导零），用上述规则机械生成 `(input, target)`。
- **课程数据组成**（第 `d` 阶段）：
  - 当前沿 `d` 位：约 50%
  - 旧长度 `1..d-1` 均匀：约 50%（保留旧数据，防灾难性遗忘）
- **划分**：
  - 训练/验证：在已见长度内随机采样。
  - 外推测试集（5–8 位）：全部为模型未见过的长度，按构造无泄漏。
  - ≥3 位时加法空间巨大，随机采样即可保证训练/测试题目不重叠；1 位空间小（100 组合），基本为记忆，属预期。

## 6. 模型（`model.py`）

微型 decoder-only Transformer：

- 2 层、隐维 128、4 头、FFN 512（约几十万参数）
- 字符级分词，自回归生成（teacher forcing 训练）
- **位置编码**：默认 **ALiBi**（线性注意力偏置，天生支持长度外推）。绝对学习式 PE 在超长位置直接失效，不用。位置编码列为可消融旋钮（可对照 NoPE）。
- 损失：仅对**生成部分**（`=` 之后的 scratchpad 列 + 答案）token 做交叉熵；输入 prompt（`a+b=`）部分不计入损失（label masking）。

## 7. 训练 / 课程调度（`train.py`）

逐级 `d = 1 → 2 → 3 → 4`：

- 每阶段用「第 5 节」的数据组成训练。
- **毕业判据**：长度 `d` 验证精确匹配准确率 ≥ 95% **或** 达到该阶段最大 epoch 上限（防卡死）。
- 毕业后进入下一阶段；保留上一阶段 checkpoint。
- **全程记录**每个长度（1–8）的准确率曲线（看课程爬升 + 旧长度是否遗忘 + 外推位的预毕业表现）。
- 梯度裁剪；留意 grokking（可能需要较长训练才突然贯通）。

## 8. 评估（`eval.py`）

- **主指标**：逐长度**精确匹配准确率**（整串答案全对），报 1–8 位。
- **外推曲线**：准确率 vs 位数（5–8）——头条结果，预期优雅衰减或断崖。
- **进位诊断**：scratchpad 每列 `数字c进位` 是否正确（定位错误在「算」还是「抄」）。
- **遗忘探针**：训练全程追踪长度 1/2/3 准确率是否保持（量化灾难性遗忘）。
- 产出：外推曲线图 + 课程阶段遗忘探针曲线（matplotlib）。

## 9. 工程结构

设计为可独立测试的小单元，每个文件单一职责：

```
deeplearn/
├── data.py     # 加法对生成 + scratchpad 格式 + 分词 + Dataset
├── model.py    # 微型 decoder-only Transformer（含 ALiBi）
├── train.py    # 课程循环 + 毕业判据 + checkpoint
├── eval.py     # 逐长度准确率 + 外推 + 遗忘探针
└── run.py      # 串联课程阶段、产出曲线图
```

**测试/护栏**：

- `data.py` 的 scratchpad 生成做单元测试：已知输入 → 已知输出，覆盖进位、变长、余进位。
- 模型先用 ~10 个样本做「过拟合小批量」健全性检查（标准 NN 自检）。
- 分词器 round-trip 测试（编码→解码还原）。

## 10. 成功标准

- 整条管线在 CPU 上跑通，产出外推曲线 + 遗忘探针曲线。
- 4 位训练准确率达标（≥95%）。
- 5–8 位外推准确率显著高于「朴素左→右无 scratchpad」基线（后者此处预期接近 0）——验证 scratchpad 对长度外推的作用。

## 11. 可消融旋钮（实现后按需开启）

1. Scratchpad 格式：竖式（逐列）↔ 内联 `d5 c1 ...` 写法对照。
2. 训练位数：训 4、测 5–8 ↔ 调大调小。
3. 位置编码：ALiBi ↔ NoPE 对照。
4. 课程 vs 混合 [1..4] 直接训的对照（验证课程对外推是否真有帮助）。

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| Grokking 需要长时间训练才贯通 | 设合理的 max-epoch 上限；记录 loss/acc 全程曲线便于诊断 |
| 课程升级时旧长度遗忘 | 数据组成保留 50% 旧长度 + 全程遗忘探针监控 |
| CPU 训练慢 | 模型保持微型；数据量按需；可先小规模验证管线再放大 |
| 外推仍不理想 | 依次排查：scratchpad 正确性 → PE 选择 → 模型容量/训练步数 |
